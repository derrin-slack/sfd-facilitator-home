# SFD Facilitator Home pieces

Interactive pieces for the STEM From Dance Clubs community on Disco, served with GitHub Pages and embedded in Disco with an iframe.

| Page | What it does |
|---|---|
| `start-here.html` | Three-step checklist. Ticks save on the facilitator's device. |
| `module-flow.html` | Four steps for every module: print Pathway Passports, teach, survey, sticker. |
| `module-picker.html` | Pick grade and interest to find a module. |

Links that still say `[...]` need real addresses (Ask & Share, printables, survey).

Embed code for Disco:

```html
<iframe src="https://derrin-slack.github.io/sfd-facilitator-home/start-here.html" width="100%" height="720" frameborder="0"></iframe>
```
